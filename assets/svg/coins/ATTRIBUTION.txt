Monogram placeholders (everything else — as of 1.5.34 only cats, cns, hmstr,
hotcross, mrsoon, myro, now, ntvrk, plx, quack, super, xym, none of which have a
logo in any of the openly-licensed sources above) are auto-generated,
deterministically-colored circle + ticker-initials SVGs, wholly original and
not derived from any brand's actual logo. They exist so every coin renders as
a real icon tile instead of a plain text tile in the checkout/admin coin
picker; swap any of them for a proper brand mark whenever one becomes
available. Regenerate via scratchpad/gen_monogram_icons.php if the coin list
changes and new tickers need a placeholder.
